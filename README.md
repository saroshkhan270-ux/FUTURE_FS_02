# Lead Management CRM

A Client Lead Management System developed as part of the Future Interns Full Stack Web Development Internship – Task 2.

## Features

- Add new leads
- View all leads
- Track lead source
- Manage lead status
- Status options:
  - New
  - Contacted
  - Converted
- Add notes and follow-up details
- Dashboard with lead statistics
- Delete leads
- MySQL database integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
